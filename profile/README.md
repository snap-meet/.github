## ✨ About Snapmeet

**Snapmeet** is an event discovery, management, and ticketing platform built to make events easier to discover, organize, and experience.

From discovering events and registering for them to creating events, managing attendees, and handling event-day entry, Snapmeet brings the essential event experience together in one place.

Whether it is a college fest, conference, workshop, cultural gathering, competition, community event, or other live experience, Snapmeet helps connect the people organizing events with the people looking to be part of them.

---

## 🌟 What Snapmeet Offers

### 🔎 Discover

Find events that match your interests, location, and plans.

- Explore events across categories
- Browse upcoming events
- Search and filter events
- View event details and schedules
- Discover events from organizers and organizations
- Explore events happening around you

---

### 🎟️ Experience

Make joining an event simple and convenient.

- Streamlined event registration
- Multiple ticket/pass options
- Custom registration information
- Digital event tickets and passes
- QR-based event entry
- Access important event information
- Stay connected with event updates

---

### 🎪 Organize

Give organizers the tools they need to create and manage their events.

- Create and publish events
- Add event details, schedules, venues, and media
- Create different ticket/pass types
- Configure registration forms
- Manage registrations and attendees
- Manage event information
- Share events with the audience
- Access organizer dashboards and reports
- Export attendee information where supported

---

### 📱 Event-Day Operations

Make entry and event-day management easier for organizers and venue teams.

- QR-based ticket scanning
- Fast attendee verification
- Event check-in management
- Duplicate-entry detection
- Mobile-friendly scanning experience
- Support for environments with limited connectivity where available
